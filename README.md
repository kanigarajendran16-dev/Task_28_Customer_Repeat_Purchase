# Customer Repeat Purchase Analysis

## Veda Technology – Data Analytics Internship

### Task 28 – Customer Repeat Purchase Analysis

Customer Repeat Purchase Analysis is a data analytics project developed as part of the Veda Technology Data Analytics Internship.

The project focuses on understanding customer loyalty, identifying repeat customers, calculating repeat purchase rate, comparing first-time and repeat customer Average Order Value (AOV), and segmenting customers based on their purchase frequency.

## 🎯 Objective

The main objectives of this project are:

- Identify repeat customers
- Calculate customer repeat rate
- Understand customer loyalty
- Compare first-time and repeat customer AOV
- Segment customers based on purchase frequency
- Analyze sales by category and region
- Analyze monthly sales trends
- Generate business insights
- Create an interactive dashboard

## 🔍 Customer Classification

Customers are classified based on the number of purchases.

| Purchase Count | Customer Segment |
|---|---|
| 1 order | One-Time |
| 2–3 orders | Repeat |
| 4+ orders | Loyal |
